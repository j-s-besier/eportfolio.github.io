Task

The Unit 5 activity asked me to compare two clustering animations and relate them to algorithm logic.

  • "Watch this animation of clustering and relate that with algorithm logic."
  • "Then watch this animation of clustering and relate that with algorithm logic. For this animation, start with the 'I'll choose' option followed by 'Uniform Points'."

Animation 1

The first animation shows how initial positions affect early grouping. Because the starting points are uneven, the algorithm has to correct the clusters over repeated updates.

Animation 2

The second animation makes the k-means loop clearer: assign points to the nearest centroid, recalculate the centroid, and repeat until the groups stabilise.

Relationship to Algorithm Logic

Together, the animations show clustering as an unsupervised, distance-based process. The output depends on dataset shape, chosen cluster count, and initial centroid positions.

What the Activity Demonstrated

The activity showed that clustering can reveal structure in unlabelled data, but the result still needs careful interpretation.

Learning Outcomes

Supports LO1 and LO2 through clustering logic and interpretation limits.
