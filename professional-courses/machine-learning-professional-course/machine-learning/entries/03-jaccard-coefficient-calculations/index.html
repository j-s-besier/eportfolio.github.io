Task

The Unit 5 activity asked me to calculate Jaccard similarity for Jack/Mary, Jack/Jim, and Jim/Mary using pathological test results.

Name Gender Fever Cough Test-1 Test-2 Test-3 Test-4
Jack M Y N P N N A
Mary F Y N P A P N
Jim M Y P N N N A

Data Preparation

I used only the test outcome columns and converted Y/P to 1 and N/A to 0, so the score measured shared positive results.

Name Fever Cough Test-1 Test-2 Test-3 Test-4
Jack 1 0 1 0 0 0
Mary 1 0 1 0 1 0
Jim 1 1 0 0 0 0

Formula: J(A, B) = |A ∩ B| / |A ∪ B|.

Calculations

Jack/Mary: 2 shared positives over 3 union positives, so J = 0.67.

Jack/Jim: 1 shared positive over 3 union positives, so J = 0.33.

Jim/Mary: 1 shared positive over 4 union positives, so J = 0.25.

Results

Pair Shared positives Union positives Jaccard coefficient
Jack, Mary 2 3 0.67
Jack, Jim 1 3 0.33
Jim, Mary 1 4 0.25

Jack and Mary are most similar; Jim and Mary are least similar.
