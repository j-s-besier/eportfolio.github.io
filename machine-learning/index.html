Learning Outcomes Legend

These are the four assessed learning outcomes for the module. Entries link back here when they reference LO1 to LO4.

LO1

Articulate the legal, social, ethical and professional issues faced by machine learning professionals.

LO2

Understand the applicability and challenges associated with different datasets for the use of machine learning algorithms.

LO3

Apply and critically appraise machine learning techniques to real-world problems, particularly where technical risk and uncertainty is involved.

LO4

Systematically develop and implement the skills required to be an effective member of a development team in a virtual professional environment, adopting real-life perspectives on team roles and organisation.

Reflection Journal

These reflection posts use the University of Edinburgh Reflection Toolkit's What? So what? Now what? structure to connect each unit experience with its meaning and future action.

Unit 1

What? The module opened with the role of machine learning in industry, the risks of algorithmic decision-making, and Collaborative Discussion 1 on the Fourth Industrial Revolution.

So what? My first clear learning point was that ML is not only a technical topic. It sits inside organisations, work practices, and decisions that can affect people directly.

Now what? My immediate aim is to keep the first discussion evidence clear and to link future technical work back to professional judgement.

Unit 2

What? This week I worked through exploratory data analysis: understanding datasets, checking anomalies, using visual analysis, and preparing data before modelling.

So what? This made the workflow more disciplined. A model can only be meaningful if the feature choices and data quality checks are reasonable first.

Now what? For the next practical work, I need to check what the data represents before thinking about algorithms, especially missing values, outliers, and whether features fit the question.

Unit 3

What? This unit introduced correlation and regression, and I ran notebooks for covariance, Pearson correlation, linear, multiple, and polynomial regression.

So what? The activity clarified that correlation describes association, while regression creates a predictive relationship. The data shape affected which method made sense.

Now what? My next step is to check plots and fit before accepting a regression result, rather than assuming one linear model will suit every dataset.

Unit 4

What? This week moved regression into Scikit-Learn, including single-variable regression, multivariate regression, and model evaluation.

So what? This was the first point where the modelling process felt more like a reusable workflow: prepare features, fit a model, evaluate, and improve.

Now what? For my next notebooks, I need to show the modelling steps clearly enough that another person could follow and question them.

Unit 5

What? In this unit I worked with distance measures, K-means, agglomerative clustering, cluster evaluation, the wiki activity, and the Jaccard calculation.

So what? The main shift was from prediction to similarity. I had to think about how representation changes the result, especially with binary symptom data and grouped points.

Now what? I need to separate the task type first: comparing records, grouping observations, or predicting values require different evidence and different caution.

Unit 6

What? For this project submission, we applied K-means in Python with Scikit-Learn around a real dataset.

So what? The team work made clustering less abstract. The choice of features, K value, and interpretation had to support a business question, not just produce clusters.

Now what? I need to keep the project notebook as an evidence trail, where preprocessing, model decisions, and limitations are visible and defensible. Each technical step should link back to the project question.

Unit 7

What? This unit shifted into artificial neural networks, activation functions, weight adjustment, and the perceptron notebooks.

So what? The simple perceptron and AND examples showed how weighted inputs create decisions. The multi-layer example showed why one layer is not always enough.

Now what? When I meet another neural-network example, I need to check whether the problem is linearly separable before assuming a simple model structure will work.

Unit 8

What? In this ANN training work, I covered backpropagation, error reduction, the gradient cost-function activity, and the start of Collaborative Discussion 2 on AI writers.

So what? I saw two sides of learning systems: technical optimisation through error reduction, and professional risk when generated outputs are fluent but uncertain.

Now what? I need to record parameter changes and ethical assumptions explicitly, because both can affect whether a result should be trusted.

Unit 9

What? This computer-vision unit brought in CNNs, real-world applications, and the object-recognition notebook with a changed test-image prediction.

So what? The activity showed that architecture is only part of the judgement. Validation behaviour and individual prediction examples affect confidence in the model.

Now what? I need to look beyond headline accuracy by checking class behaviour, prediction examples, and whether the evidence supports the claim being made.

Unit 10

What? This NLP week covered transformer-based models, evaluation metrics, and the final stage of Collaborative Discussion 2.

So what? The AI-writer discussion connected directly to NLP evaluation: fluent language is not the same as correctness, accountability, or useful performance.

Now what? I should treat text-generation outputs as drafts requiring disclosure, checking, and human responsibility. I also need to verify polished wording against source, context, and possible bias.

Unit 11

What? This unit focused on model selection, evaluation, hyperparameter tuning, MLOps, the performance-measurement notebook, and the individual presentation.

So what? The practical lesson was that evaluation must match the task. AUC, R2, accuracy, and loss answer different questions and can support different decisions.

Now what? I need to defend model choices with more than one metric and explain why the chosen evidence fits the problem. For the presentation, this means comparing validation accuracy, test accuracy, and loss before selecting the final CNN model.

Unit 12

What? This final unit returned to Industry 4.0, future ML trends, digital twins, Industry 5.0, and the final e-portfolio submission.

So what? Looking across the module at this point, my strongest learning was the link between method, evidence, teamwork, and professional responsibility.

Now what? My development target from here is to keep ML work concise, reproducible, and clear about assumptions, limits, and impact. The final portfolio should show reflection tied to evidence, not general statements.
